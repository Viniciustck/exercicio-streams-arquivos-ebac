# Atividade: Leitura de Arquivos e Conversão XML (Java)

Este projeto foi desenvolvido como parte das atividades do curso da **EBAC**, com o objetivo de praticar a manipulação de fluxos de dados (Streams), leitura de arquivos e POO em Java.

##  Descrição da Atividade

O desafio consiste em:
1. Criar um arquivo base com dados sistemáticos (separados por um delimitador).
2. Ler este arquivo via programação Java.
3. Aplicar uma regra de separação para interpretar cada linha.
4. Converter os dados lidos em Objetos Java.
5. Exibir os dados processados no console em formato **XML**.
